# PetriObjModelPaint

Бібліотека Стеценко для моделювання мереж Петрі.

Джерело: [StetsenkoInna/PetriObjModelPaint](https://github.com/StetsenkoInna/PetriObjModelPaint).

- `PetriObjModelPaint-34116fb.jar` — бібліотека та її залежності.
- `PetriObjModelPaint-sources/` — вихідний код математичного ядра для перегляду в IntelliJ IDEA.
- `dependency-lock.json` — версія джерел і контрольна сума JAR.

Бібліотеку підключено до модуля в `cursova-b2-petri.iml`. Ліцензії збережені в цьому каталозі.
